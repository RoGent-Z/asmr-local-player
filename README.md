## 浏览器本地日语音声翻译（v0.0.11）

打开音轨后点击“本地日语”（手机在⋯内），选择“识别音频并词库翻译”后开始：Vosk在浏览器本机将日语音频听写为带时间轴的日文，再通过网站内置217,538条日中词条和明确规则生成中文参考。不调用AI翻译／收费接口，不要求Key／账号／本地服务。也可只翻译已有字幕。结果可原／译／双语应用到播放器及Folia，导出VTT/SRT/JSON。

第一次需要下载约82MB语言资源；词库进入IndexedDB，语音库由Vosk本机文件系统缓存，后续优先复用。需要较多运行内存，低内存设备可先使用字幕翻译；长音频分片解码，远程音源按需Range读取。取消／换轨停止旧任务，原字幕可还原；结果保留当前页面，需长期保存时请导出。清语言缓存不清曲库。

翻译是词库匹配和语法规则，不保证自然语序、多义词、耳语或多人重叠识别正确；未匹配词保留原文，匹配率不是准确率。语音识别本身使用用户已允许的本地模型；翻译阶段没有翻译模型。词库来源与许可见third-party/LOCAL-LANGUAGE-NOTICES.txt：JMdict/EDRDG及Tomoshi(Y1Z)中文层，派生数据CC BY-SA4.0，上游释义含预先生成与审校内容；运行时不调用这些生成模型。Vosk运行库／日语模型Apache2.0。

网页初次打开仍需网络。资源准备后，已打开页面可断网处理本机音频；不承诺浏览器未缓存网页时能离线打开。手机真机与所有旧浏览器尚未逐一验证。

## 原背景与自适应光色（v0.0.10）

Folia使用当前选择的作品背景图，适度模糊并压暗保留图像轮廓；透视图元作为透明光效叠层。文字动效保留，辉光、光束、星芒、描边随背景图片主色改变。通过“作品背景”更换时立即同步；退出Folia恢复普通清晰背景。灰度图使用中性色；无图恢复暗色，跨域限制导致无法取色时仍显示原图并回退中性光。取色只在图片变化时在浏览器本机采样，不上传图片或调用AI。

## Folia 文字动效与光场（v0.0.9）

Folia模式新增独立场景渲染：青绿色透视棋盘、斜光、光尘与星芒，大号描边文字残影，当前字形辉光与装饰扫光，宽屏横竖构图及媒体时间驱动的镜头聚焦。短句大字、长句内部滚动、左右同时发言均保留；手机保留光场并压缩侧边排版。暂停冻结、跳转重建同一时刻画面，系统减少动态效果时呈现静态构图；Canvas不可用时回退为CSS背景与可读字幕。

顶部Folia/手机⋯菜单仍可随时关闭，开关与原偏好兼容。字幕没有字词时间时，扫光属于视觉装饰，实际字幕按整句同步。参考 [Folia绘光渲染分层](https://github.com/chthollyphile/folia-major/tree/aecd330b720eb8fc728e6b10ebcec261b144d683/src/components/visualizer/lumiere)，代码与场景独立实现，不增加音乐服务、AI、账号或网络请求。

## Folia 字幕舞台（v0.0.8）

顶部“Folia”可随时切换沉浸字幕舞台，默认关闭，偏好保存在当前浏览器。当前句聚焦、已读/即将出现的句子淡显，支持左右同时发言、长句滚动、字幕间奏和点击句子跳转；不会更换音源或改变听音/同步方式。无字幕或载入中回到普通视图，有字幕时自动恢复所选模式；AI导入/原文/译文切换同步更新。舞台有始终可用的退出按钮，Escape可退出，尊重减少动态效果设置。

设计参考 [Folia](https://github.com/chthollyphile/folia-major) 的沉浸式文字呈现，使用本项目原生DOM/CSS独立实现，未复制其代码或资源。现有字幕只有句子时间戳，动效按整句处理，不模拟逐字对齐。不增加网络请求或AI服务调用。

## 统一作品库（v0.0.7）

欢迎页三个入口采用等宽等高布局，桌面并排、手机整齐堆叠。点击“添加作品网址”或“在线作品”，粘贴公开 HTTP(S) 网页、音频直链或 M3U/PLS/XSPF 普通音频列表，即可提取音轨、字幕与封面；ASMR.one 继续自动适配。无需访客账号、Key 或本地服务。支持网页公开的 audio/source、音频链接和 JSON-LD AudioObject；需登录、DRM、HLS分段流或没有公开媒体地址的动态网页会明确提示能力边界。

本机和在线作品使用相同层级卡片，在线作品标题旁有小云图标。在线目录自动保存在浏览器，音频按需串流；通用来源通过本站解析服务转发媒体及Range，ASMR已验证CDN继续直连。来源不可用或地址过期时，可刷新目录重试。格式选项按实际文件提供，浏览器解码能力决定是否可播放。

本机曲库同样自动记住：支持目录句柄时保存目录授权，允许访问时自动恢复；需要重新授权时点击“恢复曲库访问”。文件选择兼容模式把实际使用的音频、字幕、图片及净化分析资料写入此设备的IndexedDB，刷新或重开后自动恢复。缓存状态在作品库内可查看。配额、权限或写入失败会明确说明，并保留上次完整快照；可清除本机缓存。在线音频只在主动下载时保存文件。

“下载作品”默认选择当前音频格式、匹配字幕、图片及官方封面，可展开“自选下载文件”逐项勾选。下载保留相对目录。支持目录写入的桌面浏览器逐文件保存；其他浏览器交给下载管理器保存流式 ZIP。兼容模式使用最多 128 MiB 的 ZIP 分卷，过大的单文件交给原生下载。交给浏览器不代表磁盘已经写入成功，须查看浏览器下载列表。手机后台挂起或关闭页面可能中断下载。

在线打开网页后，点击“选择曲库文件夹”，选择本机项目目录、分类目录、作品目录或普通音频文件夹，即可在浏览器中播放 MP3/WAV 并读取同名 VTT、SRT、ASS、SSA、LRC 字幕。不支持目录选择的手机可使用“选择音频与字幕文件”。

## v0.0.3 功能

- 字幕自动发现与 AI 工作台导入新增 SRT、ASS/SSA、LRC；支持 UTF-8、带 BOM 的 UTF-16 和 Shift-JIS。ASS/SSA 保留时间、文字和人物，忽略字体、定位与特效。LRC 按下一时间点结束，空时间行清屏，末句最多延续 5 秒且不超过音频时长。导出仍为 VTT/SRT/JSON。

## 使用与隐私

- 本机曲库播放只读取你主动选择的文件夹，媒体不会上传到 GitHub。在线作品播放会请求本站解析服务及来源 CDN。AI 字幕是可选功能，只有你填写接口并点击开始后，才将当前音轨的音频分片发给识别服务、台本发给翻译服务。
- 刷新或重新打开网页后自动尝试恢复本机缓存及在线目录；原目录授权失效或浏览器清理数据后，需要恢复访问或重新选择文件夹。
- 播放进度只保存在当前浏览器的本地存储中；重新选择同一曲库可恢复进度，换浏览器或清除网站数据会失去记录。
- 如果浏览器弹出“上传文件夹”的系统提示，这只是目录选择器的默认用语；选择曲库本身不会上传文件。

## 自有 AI API

在 AI 字幕工作台分别填写完整 HTTPS 接口、模型 ID 与 API Key：语音识别使用兼容 /audio/transcriptions 的接口和带逐段时间戳的语音模型（verbose_json 或 diarized_json）；翻译使用兼容 /chat/completions 的文字模型。两个服务可以不同。内置提示词保留多人身份、口语、低语、拟声及术语，时间由程序固定。

接口须允许浏览器跨域（CORS）。普通文字模型不一定能识别音频，不承诺任意模型或原生私有协议直接兼容。AI 功能不提供公共中转、不代付 API 费用；请使用自己的可信接口。Key 只留在当前页面，刷新后需重新填写，不写入代码、浏览器持久存储或导出。

结果仅保留在当前页面。JSON 保存全部来源的原文、译文及时间，可重新导入恢复；VTT/SRT 按工作台中选定的音源导出原文件时间轴。耳语、重叠发言、跨片段说话人编号应人工校对。MP3 的 gapless 编码延迟可能造成小幅固定时间偏差；普通 PCM/float WAV 与 MPEG Layer III MP3 已做中性解码验证。

## 浏览器兼容

桌面建议 Edge 或 Chrome；手机提供 Android/iPhone 的触控布局与多文件选择回退。iOS Safari 18.4 起提供目录选择（https://webkit.org/blog/16574/webkit-features-in-safari-18-4/）；旧版或不支持目录的环境使用多文件入口。媒体由浏览器解码，WAV 是否可播放取决于实际编码。Edge 用于播放验证；Windows WebKit 本地音频 Blob 探针失败，其界面/导入验证使用合成媒体元数据，不能代表 iPhone 真机播放验收。

## GitHub Pages 部署

将本目录中的发布文件放在专用 GitHub 仓库的 main 分支根目录。进入仓库 Settings → Pages，将 Source 设置为 Deploy from a branch，选择 main 和 / (root)，保存后等待发布完成。即 main /root 方式，无需额外工作流。

保留 .nojekyll 文件。网页资源使用相对路径，支持仓库子路径。此仓库只应保存静态网页文件；本机曲库及项目配置不应放入仓库。
