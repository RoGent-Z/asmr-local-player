# ASMR 原声播放器 v0.0.4

在线打开网页后，点击“选择曲库文件夹”，选择本机项目目录、分类目录、作品目录或普通音频文件夹，即可在浏览器中播放 MP3/WAV 并读取同名 VTT、SRT、ASS、SSA、LRC 字幕。不支持目录选择的手机可使用“选择音频与字幕文件”。

## v0.0.4 新功能

- 左侧曲库封面从整个作品文件夹选取，优先封面名称（封面、cover、front、TOP、表紙等），其次作品根目录，再其次子目录，不按图片格式决定优先级。
- 最高优先级只有一张时自动显示；有多张时卡片提示选择。点击“选择封面/更换封面”即可挑选和记忆，也可“恢复自动选择”。封面和播放器背景分别保存，图片不上传；损坏封面从剩余图片回退。
- 曲库与台词抽屉支持 Escape 关闭、Tab 焦点约束、目录展开后焦点与滚动保持。播放被阻止时暂停进度并允许重试；加载失败时禁用播放和进度，重新选择正常音轨后恢复；末尾点击播放可重播。

## v0.0.3 功能

- 字幕自动发现与 AI 工作台导入新增 SRT、ASS/SSA、LRC；支持 UTF-8、带 BOM 的 UTF-16 和 Shift-JIS。ASS/SSA 保留时间、文字和人物，忽略字体、定位与特效。LRC 按下一时间点结束，空时间行清屏，末句最多延续 5 秒且不超过音频时长。导出仍为 VTT/SRT/JSON。
- 字幕放在音频同目录，可命名 Track1.mp3.srt 或 Track1.srt。先匹配包含音频扩展名的完整名称，再匹配去扩展名名称；各组优先级为 VTT、SRT、ASS、SSA、LRC。
- 每部作品从自身目录的 JPG/JPEG/PNG/WebP/AVIF/GIF 选择背景：无图用暗色，一图自动使用，多图首次进入时选择。点击“作品背景”可更换或恢复暗色。浏览器仅保存图片相对路径，刷新后需重新选择曲库。
- 手机顶部“⋯”收纳操作入口，字幕按左右来源堆叠，控制区保持可触摸，支持竖屏与横屏。多文件模式请同时选择音频、同名字幕和图片；系统不提供目录路径时，重名文件会提示分批选择。

## 使用与隐私

- 普通播放只读取你主动选择的文件夹，媒体不会上传到 GitHub。AI 字幕是可选功能，只有你填写接口并点击开始后，才将当前音轨的音频分片发给识别服务、台本发给翻译服务。
- 刷新或重新打开网页后，需要重新选择文件夹。浏览器不会保存下一次自动读取文件夹的授权。
- 播放进度只保存在当前浏览器的本地存储中；重新选择同一曲库可恢复进度，换浏览器或清除网站数据会失去记录。
- 如果浏览器弹出“上传文件夹”的系统提示，这只是目录选择器的默认用语；选择曲库本身不会上传文件。

## v0.02 新功能

- 默认保留原始双耳立体声，双源各以 0.5 增益混合；也可选人物分侧、仅左侧源、仅右侧源。单文件字幕不会再改变声音位置。
- 默认按原始时间播放；需要旧版共同字幕锚点同步时，选择“字幕对齐”。
- “AI 字幕”工作台支持无字幕 MP3/WAV 分段识别后翻译，或导入 VTT/SRT 后只翻译。提供取消、当前页面续做、双语显示和导出。

## 自有 AI API

在 AI 字幕工作台分别填写完整 HTTPS 接口、模型 ID 与 API Key：语音识别使用兼容 /audio/transcriptions 的接口和带逐段时间戳的语音模型（verbose_json 或 diarized_json）；翻译使用兼容 /chat/completions 的文字模型。两个服务可以不同。内置提示词保留多人身份、口语、低语、拟声及术语，时间由程序固定。

接口须允许浏览器跨域（CORS）。普通文字模型不一定能识别音频，不承诺任意模型或原生私有协议直接兼容。此静态网页不提供公共中转、不代付 API 费用；请使用自己的可信接口。Key 只留在当前页面，刷新后需重新填写，不写入代码、浏览器持久存储或导出。

结果仅保留在当前页面。JSON 保存全部来源的原文、译文及时间，可重新导入恢复；VTT/SRT 按工作台中选定的音源导出原文件时间轴。耳语、重叠发言、跨片段说话人编号应人工校对。MP3 的 gapless 编码延迟可能造成小幅固定时间偏差；普通 PCM/float WAV 与 MPEG Layer III MP3 已做中性解码验证。

## 浏览器兼容

桌面建议 Edge 或 Chrome；手机提供 Android/iPhone 的触控布局与多文件选择回退。iOS Safari 18.4 起提供目录选择（https://webkit.org/blog/16574/webkit-features-in-safari-18-4/）；旧版或不支持目录的环境使用多文件入口。媒体由浏览器解码，WAV 是否可播放取决于实际编码。Edge 用于播放验证；Windows WebKit 本地音频 Blob 探针失败，其界面/导入验证使用合成媒体元数据，不能代表 iPhone 真机播放验收。

## GitHub Pages 部署

将本目录中的发布文件放在专用 GitHub 仓库的 main 分支根目录。进入仓库 Settings → Pages，将 Source 设置为 Deploy from a branch，选择 main 和 / (root)，保存后等待发布完成。即 main /root 方式，无需额外工作流。

保留 .nojekyll 文件。网页资源使用相对路径，支持仓库子路径。此仓库只应保存静态网页文件；本机曲库及项目配置不应放入仓库。
